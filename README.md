## Weekly Assignments

### week-01 — Python Fundamentals & Machine Learning Basics

This week covers foundational concepts in Python and artificial intelligence, including how Python executes code, core AI/ML terminology, and a hands-on supervised learning exercise.

**Topics:**

- **Interpreter vs Compiler** — How Python processes and runs source code, with a side-by-side comparison of interpreted and compiled languages.
- **Big Data** — An overview of the 5V model (Volume, Velocity, Variety, Veracity, Value) that defines large-scale data challenges.
- **LLM (Large Language Model)** — How transformer-based language models work and where they are applied.
- **RAG (Retrieval-Augmented Generation)** — Architecture that combines a knowledge base with an LLM for accurate and up-to-date answers.
- **Agent** — Autonomous AI systems that reason, take actions, and use tools to reach a goal.
- **MLOps** — Practices for deploying, monitoring, and maintaining ML models in production.
- **Supervised Learning (Logistic Regression)** — Predicting whether a student passes an exam based on study hours and attendance rate.

**Files:**
- [`week-01/tercuman_derleyici.py`](week-01/tercuman_derleyici.py) — Interpreter vs Compiler concepts and demo
- [`week-01/buyuk_veri_llm_rag_agent_mlops.py`](week-01/buyuk_veri_llm_rag_agent_mlops.py) — Big Data, LLM, RAG, Agent, MLOps explanations
- [`week-01/supervised_learning.py`](week-01/supervised_learning.py) — Logistic Regression implementation
- [`week-01/notes.md`](week-01/notes.md) — Concept notes and usage instructions
