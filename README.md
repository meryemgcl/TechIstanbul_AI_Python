## Weekly Assignments

### week-01 — Supervised Learning: Logistic Regression

This week's topic covers the fundamentals of supervised machine learning. Using logistic regression, we built a simple classifier that predicts whether a student will pass or fail an exam based on their daily study hours and lecture attendance rate. The script includes model training, evaluation metrics (accuracy, confusion matrix, classification report), prediction on new samples, and a visualization of the decision boundary.

**Files:**
- [`week-01/supervised_learning.py`](week-01/supervised_learning.py) — Main implementation
- [`week-01/notes.md`](week-01/notes.md) — Concept notes and usage instructions
